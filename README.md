# Властная лексика в языке Фомы Аквинского

Репозиторий исследовательских материалов к статье «Властная лексика в языке Фомы Аквинского: дистрибутивно-семантический анализ». Выходные данные и DOI статьи добавляются после публикации.

*Supplementary materials for a distributional-semantic study of power vocabulary in Thomas Aquinas compared with Classical Latin. Notebooks and documentation are in Russian.*

## Структура

| Файл или папка | Содержание |
| --- | --- |
| `notebooks/01_models_neighbours.ipynb` | Фоновые значения μ и σ; пересечение 500 ближайших соседей (Таблица 1); ближайшие соседи (Таблица 2 и П1); стандартизованное сходство слов (Рисунки 3–5) |
| `notebooks/02_networks.ipynb` | Сети целевых слов (Таблица 3, Рисунки 1–2); сообщества и 50 запусков алгоритма Лейдена (Таблица 4); число связей и посредничество (Таблица 5); локальные сети (Рисунки 6–9, П1–П6) |
| `data/models/` | Папка для локально сохранённых исходных моделей LiLa, сами модели в архив не включены |
| `figures/` | Сохранённые рисунки статьи и приложения (PNG, 300 dpi) |
| `html/` | HTML-копии выполненных ноутбуков, включая сохранённые результаты |
| `appendix/Appendix.pdf` | Приложение к статье |
| `requirements.txt` | Зависимости Python, включая JupyterLab |

## Как запустить локально

Понадобятся **Python 3.12**, доступ к терминалу и достаточно свободного места для двух исходных моделей. Установка выполняется **один раз**, в корневой папке распакованного репозитория.

**Windows (PowerShell)**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter lab
```

Если PowerShell запрещает активацию окружения, можно обойти её и вызывать исполняемые файлы напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\jupyter-lab.exe
```

**Linux / macOS**

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

В JupyterLab откройте сначала `notebooks/01_models_neighbours.ipynb`, затем `notebooks/02_networks.ipynb`. В каждом ноутбуке можно выполнить **Run → Run All Cells**. Ноутбуки независимы друг от друга: второй не требует сохранённых промежуточных данных первого. Они пересчитывают **только исходные показатели и рисунки статьи**, не добавляя новых экспериментов или проверок. Первые обращения к моделям могут занять дополнительное время из-за их чтения.

Рисунки всегда сохраняются в `<корень репозитория>/figures/`, независимо от того, открыли ли вы Jupyter из корня репозитория или из `notebooks/`. Исходные изображения в архиве сохранены.

## Модели: повторно скачивать не нужно

Используются **исходные, несовмещённые** модели лемм проекта LiLa (FastText skip-gram, 100 измерений). Версии и контрольные суммы зафиксированы в обоих ноутбуках, изменений моделей или расчётных параметров нет.

| Модель | Имя исходного файла LiLa | Локальное имя |
| --- | --- | --- |
| Opera Latina (LASLA) | `allLASLA-lemmi-fast-100-SKIP-win5-min5.vec` | `raw_classical.vec` |
| Opera Maiora (Фома Аквинский) | `opera-maiora-lemmas_skip_100.vec` | `raw_aquinas.vec` |

Поместите уже скачанные файлы **под любым из указанных двух имён** в `data/models/`. Также автоматически распознаются файлы, ранее лежавшие в корне репозитория, `notebooks/` или `data/`. Корректный существующий файл **не перемещается и не скачивается повторно**.

При отсутствии модели ноутбук попытается скачать её по исходному адресу проекта LiLa в `data/models/` и проверит контрольную сумму SHA-256. Чтобы полностью запретить сетевые загрузки, в параметрах обоих ноутбуков установите `DOWNLOAD_MISSING_MODELS = False`. Если контрольная сумма локального файла не совпадает с ожидаемой, ноутбук прекращает работу и не перезаписывает файл. Это помогает не спутать исходные модели с выровненными моделями или версиями с другими настройками.

Если Jupyter запускается из нестандартной папки вне репозитория, можно указать переменную окружения `AQUINAS_PROJECT_ROOT` с полным путём к репозиторию.

Сведения о моделях: Sprugnoli R., Passarotti M., Moretti G. *Vir is to Moderatus as Mulier is to Intemperans. Lemma Embeddings for Latin* (2019); Sprugnoli R., Moretti G., Passarotti M. *Building and Comparing Lemma Embeddings for Latin. Classical Latin versus Thomas Aquinas* (2020).

## Что изменено в локальной версии

В отличие от исходного архива, ноутбуки **не устанавливают пакеты самостоятельно**. Обнаружение папки проекта и локальных копий моделей не зависит от текущей директории. Хеширование моделей выполняется частями, а недокачанный файл не заменяет существующий. Пути сохранения рисунков направлены в корень репозитория. Исследовательский словарь, параметры и формулы, а также сохранённые ранее результаты **не изменены и не пересчитывались при подготовке данной версии**.

Сохранённые выходы в `.ipynb` и `html/` относятся к прежнему выполнению ноутбуков. Обновлённые ячейки подготовки среды и загрузки файлов не требуют изменения численных результатов; при желании можно повторить исходное выполнение локально.
