# Господство, полномочия, правление: лексика власти у Фомы Аквинского

Материалы исследования контекстных связей десяти латинских обозначений власти в сочинениях Фомы Аквинского. Анализ выполнен на основе **одной модели** лемм проекта LiLa — *Opera Maiora* (*Index Thomisticus*) — с использованием косинусного сходства, сетевого анализа и алгоритма Лейдена.

Репозиторий сопровождает статью «Господство, полномочия, правление: лексика власти у Фомы Аквинского». Библиографические сведения о публикации и DOI будут добавлены после её выхода.

*Supplementary materials for a distributional-semantic and network analysis of ten Latin terms of power in Thomas Aquinas, based on the LiLa Opera Maiora lemma embeddings. Documentation and notebooks are in Russian.*

## Задача исследования

Цель — выявить устойчивые контекстные связи слов *dominium, potestas, praelatio, iurisdictio, regimen, gubernatio, principatus, regnum, auctoritas* и *imperium* и сопоставить их с употреблением и определениями этих слов в сочинениях Фомы. Сетевые сообщества рассматриваются как группы преимущественно близких контекстов, **а не** как готовая классификация видов власти в его учении.

В актуальной версии **не используется сопоставление моделей *Opera Latina* и *Opera Maiora***. Модель *Opera Maiora* также не переобучается: анализируются опубликованные векторы.

## Данные и основные параметры

- **Модель:** `opera-maiora-lemmas_skip_100.bin`, fastText skip-gram, 100 измерений, окно 10, минимальная частота 5; словарь модели — 6724 леммы.
- **Исходные слова:** 10 указанных выше лемм; для каждой выбираются 15 ближайших соседей, затем повторяющиеся слова удаляются.
- **Основная сеть:** 122 леммы; косинусное сходство рассчитывается для каждой пары отобранных лемм; порог связности — 0,59; 715 рёбер.
- **Сообщества:** алгоритм Лейдена, 50 запусков с разными случайными инициализациями; основное разбиение — медоид серии (7 сообществ; модулярность 0,4945).
- **Устойчивость:** повторный отбор по 10 и 20 соседей вместо 15, по 50 запусков Лейдена для каждого варианта; дополнительная проверка порога 0,60.
- **Локальные сети:** схема 6–4 — шесть ближайших соседей исходной леммы и по четыре соседа каждого из них.

Числа относятся к сохранённым результатам актуального расчёта с **десятью** исходными леммами. Коэффициенты косинусного сходства выражают близость контекстов в данной модели, а не тождество значений слов.

## Запуск

Рекомендуется Python 3.12 и JupyterLab. Из корня репозитория создайте виртуальное окружение и откройте ноутбук.

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

**Linux / macOS:**

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Команды с `requirements.txt` работают при наличии этого файла в репозитории. Исполненный основной ноутбук содержит также ячейку, устанавливающую отсутствующие Python-библиотеки. Если `requirements.txt` отсутствует, установите JupyterLab (`python -m pip install jupyterlab`) и запустите основной ноутбук: он установит недостающие перечисленные в нём зависимости.

Откройте `notebooks/01_main_analysis.ipynb` и выполните ячейки по порядку (**Run → Run All Cells**). Ноутбук использует путь `../models/`, `../tables/` и `../figures/`, если запущен из папки `notebooks/`; при запуске из корня репозитория — соответствующие папки корня. При запуске в Google Colab результаты сохраняются относительно текущего рабочего каталога.

### Модель LiLa

Для воспроизведения требуется только:

```text
models/opera-maiora-lemmas_skip_100.bin
```

Источник: [LiLa — Opera Maiora, fastText skip-gram 100](https://embeddings.lila-erc.eu/samples/download/OperaMaiora/opera-maiora-lemmas_skip_100.bin). Размер загрузки — около 770 МБ.

Если файл уже находится в `models/`, ноутбук повторно его не загружает. При отсутствии файла ноутбук пытается скачать его по приведённому адресу. После чтения проверяется контрольная сумма SHA-256:

```text
4f973ddb57a9a382b13345c72269c628f10bae1b4b279f26dca9168697b44f5c
```

Для работы без доступа к сети поместите модель в `models/` **до запуска** ноутбука. Исходный код текущего расчёта не содержит переключателя `DOWNLOAD_MISSING_MODELS`, упоминавшегося в прежнем README.

## Воспроизводимость и ограничения

Параметры отбора слов, выбора порога, инициализации и алгоритма Лейдена указаны в основном ноутбуке. Проверки устойчивости касаются построения сети и её разбиения; они **не** являются проверкой разных обучений модели fastText. Близость слов также может зависеть от их сходного написания, поскольку fastText учитывает символьные фрагменты слов.

*Opera Maiora* объединяет произведения разного времени и тематики. Один вектор соответствует всем контекстам леммы, включая цитаты. Поэтому результаты характеризуют словоупотребление представленного корпуса и требуют проверки по конкретным латинским текстам. Сопоставление с текстами Фомы и историографией выполнено в статье и её приложении.
