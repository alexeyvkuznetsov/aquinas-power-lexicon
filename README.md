# Господство, полномочия, правление: лексика власти у Фомы Аквинского

Код, таблицы, рисунки, приложение и подборка контекстов к статье А. В. Кузнецова «Господство, полномочия, правление: лексика власти у Фомы Аквинского». Сведения для цитирования — в разделе «Как цитировать» и в файле `CITATION.cff`.

*Code, tables, figures, an appendix and selected Latin contexts for a distributional-semantic and network analysis of eleven Latin terms of power in Thomas Aquinas, using the LiLa Opera Maiora lemma embeddings. The documentation and notebook are in Russian.*

## Задача

Выявить устойчивые контекстные связи слов *dominium, potestas, praelatio, iurisdictio, regimen, gubernatio, principatus, dominatio, regnum, auctoritas* и *imperium* в сочинениях Фомы Аквинского и сопоставить их с употреблением этих слов в его текстах и с выводами историографии. Сообщества сети понимаются как группы слов с близкими контекстами, а не как классификация видов власти.

## Данные и метод

| Шаг | Параметры |
| --- | --- |
| Модель | `opera-maiora-lemmas_skip_100.bin` проекта LiLa: fastText skip-gram, 100 измерений, окно 10, минимальная частота 5; 6724 леммы. Модель используется в опубликованном виде и не обучается заново |
| Словарь сети | 11 целевых лемм и по 15 ближайших соседей каждой; после объединения 125 лемм |
| Основная сеть | 125 узлов и 724 взвешенных ребра при пороге сходства 0,59 — наибольшем в проверенной сетке 0,30–0,80 (шаг 0,01), сохраняющем связность |
| Сообщества | алгоритм Лейдена (взвешенная модулярность), 50 запусков; основное разбиение — медоид серии: 7 сообществ, модулярность 0,4941 |
| Локальные сети | схема 6–4: шесть ближайших соседей леммы и по четыре соседа каждого из них |
| Устойчивость | При 10, 15 и 20 соседях: соответственно 92, 125 и 164 узла; пороги 0,60, 0,59 и 0,58; по 50 запусков Лейдена. При повышении порога основной сети до 0,60 отделяется *possideo*, остальные 124 леммы (включая все целевые) остаются в главной компоненте |
| Сеть ближайших соседей | *union k-NN*: внутри тех же 125 лемм связь проводится, если хотя бы одна лемма входит в число восьми ближайших соседей другой (k = 8); 677 рёбер, в том числе 155 со сходством ниже 0,59 |
| Исключение редких лемм | из основной сети удалены 20 нецелевых лемм с частотой ниже 10; остаются 105 лемм и 513 рёбер |

## Запуск

Нужны Python 3.12 и JupyterLab.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Откройте `notebooks/01_main_analysis.ipynb` и выполните все ячейки по порядку. Результаты записываются в `tables/` и `figures/`.

### Модель

Ноутбук ищет файл `models/opera-maiora-lemmas_skip_100.bin`. Каталог `models/` в репозитории пуст: файлы моделей исключены в `.gitignore`. Если файла нет, он загружается с сайта проекта LiLa (около 770 МБ): <https://embeddings.lila-erc.eu/samples/download/OperaMaiora/opera-maiora-lemmas_skip_100.bin>. После чтения проверяется контрольная сумма SHA-256:

```text
4f973ddb57a9a382b13345c72269c628f10bae1b4b279f26dca9168697b44f5c
```

Для работы без доступа к сети положите файл в `models/` до запуска.

## Ограничения

- Используется одна опубликованная модель. Проверки относятся к построению сети и её разбиению, но не к обучению модели: оно не повторялось.
- Косинусное сходство отражает близость контекстов и не равнозначно близости значений. Оно зависит и от написания слов, поскольку fastText учитывает их буквенные фрагменты.
- Одной лемме соответствует один вектор для всех её употреблений, включая цитаты. Разные значения слова не разделяются.
- *Opera Maiora* объединяет сочинения разного времени и тематики. Трактат «О царстве» и комментарий к «Политике» в корпус не входят.
- Порог 0,59 определён формальным критерием: это наибольшее проверенное значение с шагом 0,01, при котором выбранный словарь образует связную сеть. Он зависит от состава словаря, в особенности от *possideo*, и не является универсальной границей значимой близости.
- Число ближайших соседей (N = 15), k = 8 для альтернативной сети и схема локальных сетей 6–4 — рабочие параметры. Влияние N проверено при 10 и 20; исключение частот ниже 10 применялось отдельно к нецелевым леммам для проверки устойчивости.

Сопоставление результатов с текстами Фомы и историографией дано в статье; использованные при этом места собраны в `contexts/`.
