# Таблицы результатов

Здесь размещены таблицы, извлечённые из **выполненных экспортов ноутбуков**, а не вновь рассчитанные в процессе подготовки репозитория. Для основного анализа использован HTML-экспорт выполненного расчёта, для классического фона — отдельный HTML-экспорт сравнительного анализа.

**Точность:** отображение HTML округляет некоторые показатели (например, косинусное сходство до трёх знаков). Поэтому исходные сохранённые CSV с полной машинной точностью можно получить только повторным выполнением соответствующих ноутбуков. Таблицы `top15_neighbors.csv` и `network_node_sources.csv` реконструированы из отображённого Top-15; матрица `co_membership_N15.csv` реконструирована без потери точности из 45 показанных пар и диагонали 50/50.

Наиболее существенные файлы: `communities_medoid.csv` (полный состав семи сообществ), `robustness_pairs.csv` (45 пар, N=10/15/20), `pairwise_similarity.csv` (косинус и ранги), `top15_neighbors.csv`, `classical_neighbors.csv`.

**`threshold_scan.csv` намеренно отсутствует в предрассчитанных результатах:** построчная таблица сканирования порогов не присутствует в HTML. Она автоматически создаётся при выполнении основного ноутбука, как и полные числовые версии прочих CSV.
